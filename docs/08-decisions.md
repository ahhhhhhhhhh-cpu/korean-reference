## 使用说明

本文档记录项目中的重要技术与产品决策。当文档之间出现冲突时，以**更新日期更晚、层级更具体**的文档为准，并在此记录决策理由。

**格式：**

- **ID**：决策编号
- **日期**：决策日期
- **状态**：已接受 / 已废弃 / 待确认
- **背景**：为什么需要决策
- **决策**：最终选择
- **理由**：选择原因
- **影响**：对项目的影响

### DEC-003：URL 国际化结构

|------|------|
| 日期 | 2026-08-03 |
| 状态 | 已接受 |
| 背景 | 需在 SEO、分享、刷新保留语言之间权衡 |
