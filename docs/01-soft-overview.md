## S — Scope（范围）

### 项目定义

Korean Reference 是一个面向韩语学习者的在线查询网站，帮助用户快速理解韩语中的音变规则、发音变化、用言变形、不规则用言、汉字词、常用习语、词汇释义及例句。

### 目标用户

| 优先级 | 用户群体 | 说明 |
|--------|----------|------|
| 1 | 中文母语者 | 第一版内容质量基准，维护者优先校对 |
| 2 | 英语母语者 | 完整界面与主要知识内容 |
| 3 | 日语母语者 | 完整界面与主要知识内容 |

用户无需注册或登录即可使用核心查询功能。

### 第一版核心模块

1. **综合查询** — 韩文词语统一搜索入口
2. **音变查询** — 规则浏览与词条关联
3. **用言变形查询** — 常见动词/形容词词尾变化
4. **汉字词查询** — 韩文与汉字来源关系
5. **习语查询** — 惯用表达与固定搭配
6. **多语言解释** — 界面与知识内容三语支持（zh / en / ja）
7. **错误反馈** — 用户提交问题，不直接修改正式内容
8. **响应式页面** — 桌面、平板、手机统一适配

### 第一版明确不包含

- 人工智能问答或实时翻译
- 用户注册、登录、收藏、个人词表
- 评论区、社交功能、付费会员
- 完整自动句子发音分析
- 覆盖全部韩语词汇的大型词典
- 网站内完整管理员后台（`/admin`）
- 原生 Android / iOS 应用
- 罗马字搜索作为核心功能
- 国际音标（IPA）

### 初始内容规模建议

| 内容类型 | 建议数量 |
|----------|----------|
| 核心词条 | ~100 |
| 音变规则 | 20–30 |
| 用言变形案例 | ~30 |
| 汉字词 | ~50 |
| 习语 | ~30 |

开发 Seed（用于测试）：10–20 词条、5 条音变规则、5 个用言、5 个汉字词、5 条习语。

## O — Objectives（目标）

### 用户目标

- 快速找到所需韩语信息
- 理解音变产生的原因与过程
- 查询用言变形及不规则类型
- 了解汉字词来源与构词
- 理解习语的实际含义与使用场景
- 对比中、英、日三语解释
- 通过例句理解实际用法
- 发现错误时向维护者反馈

### 产品目标

1. 用户无需登录即可查询
2. 查询流程简单直观
3. 电脑端与手机端均可正常使用
4. 内容结构支持持续扩充
5. 网站数据与页面代码分离
6. 正式内容保存在 Supabase PostgreSQL
7. 普通用户只有公开读取权限
8. 三语数据从第一天起独立建模
9. 通过 GitHub + Vercel 持续部署
10. 项目结构便于后续开发者或 AI 接手
11. 可作为个人作品集展示

## F — Flow（流程摘要）

详细流程见 [03-user-flows.md](./03-user-flows.md)。

| 流程 | 要点 |
|------|------|
| 首次进入 | 默认英文；`/` 跳转或推荐至 `/en`；语言偏好存 localStorage |
| 综合查询 | 搜索 → 建议 → 结果 → 词条详情（长滚动 + 锚点导航） |
| 音变 | 规则列表（平铺 + 标签筛选）或从词条进入 |
| 用言变形 | 选词/输入原形 + 选条件 → 静态步骤展示结果 |
| 汉字词 | 韩文/汉字搜索；支持单字反查相关词 |
| 习语 | 搜索 + 主题分类浏览 |
| 语言切换 | URL 同步变化；停留当前页面；内容缺失时回退英文并标记 |
| 错误反馈 | 内容页按钮 + 轻量浮动入口；Toast 成功提示 |
| 内容维护 | 管理员通过 Supabase 后台；网站只读 `published` |
| 部署 | 本地 → Git Commit → GitHub → Vercel 自动构建 |

详细架构见 [05-architecture.md](./05-architecture.md)，数据模型见 [04-data-model.md](./04-data-model.md)。

| 测试 | Vitest + Playwright（逐步引入） |

### 数据接入策略

```
Demo 阶段：本地 Mock（JSON / TypeScript）
    ↓ 页面结构与交互验收
正式 MVP：Supabase 读取
    ↓
部署版本：不得长期依赖页面内 Mock 数据
```

所有数据访问通过统一 Repository / Service 层，页面不直接依赖 Mock 文件。

### 多语言 URL 结构

```text
/en/entries/deutda
/zh/entries/deutda
/ja/entries/deutda
```

- 默认语言：英文（`/` → `/en`）
- 切换语言：URL 同步变化，Slug 不随界面语言变化
- 内容回退：当前语言缺失 → 英文（须显式标记）→ 均无则「内容准备中」

## 核心原则

1. 查询功能优先于装饰效果
2. 用户无需登录即可使用核心功能
3. 普通用户不能直接修改正式内容
4. 错误反馈与正式内容修改完全分离
5. 正式知识内容必须经过人工检查
6. 不使用 AI 实时生成查询答案
7. 数据库与页面代码分离
8. 规则、内容和翻译分别建模
9. 第一版控制数据规模，但保留扩展能力
10. 同一网站适配手机、平板和电脑
11. 每个模块尽量保持独立
12. 项目文档随开发进度同步更新
13. 稳定版本必须通过 Git Commit 保留
14. 密钥和管理员权限不得暴露给普通用户
15. 无法确认正确性的内容必须保留为 `draft`
16. 无法提供可靠结果时明确说明未收录，不猜测答案
