## v2-ex-027

**Target sense**

* 모르다 sense 2 — may; might; not be sure

**Korean**  
내일 비가 올지 모르겠어요.

**English**  
I'm not sure if it'll rain tomorrow.

**Chinese**  
不知道明天会不会下雨。

**Japanese**  
明日雨が降るかどうか分かりません。

**Approved lexical links**

* 올지 모르겠어요 → 모르다 sense 2

**Important**

* This demonstrates uncertainty through `-(으)ㄹ지 모르다`.
* The translations use the natural way of expressing uncertainty in each language.
* Do not mechanically translate `모르다` as a lexical “not know” in every locale.
